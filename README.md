# دليل SonarQube الشامل

دليل عربي لقراءة SonarQube Community Build والعمل به: ما تعنيه الأرقام، أين تُفحص، وما الذي يحكم عليه السيرفر.

افتح [الدليل الشامل](SonarQube_Guide_AR_v2.html). من الصفحة الأولى يمكن البحث، وتغيير الألوان، وتشغيل العرض التقديمي. الصور من لوحاتنا، والضغط على الرقم يشرح العنصر.

[دليل التطبيق على أي مشروع](SonarQube_Playbook_AR_v2.html) يكمّله: نفس المسار على مشروع آخر، دون إعادة شرح الشاشات.

## أقسام الدليل

| القسم | الموضوع |
|---|---|
| 1 | الخلاصة بالأرقام |
| 2 | كيف يعمل SonarQube وكيف تُقرأ أرقامه: الكود الجديد، الخريطة، وقراءة اللوحة |
| 3 | الإصدارات وحدود Community، وما يمكن ضبطه حول Sonar way |
| 4 | النتيجة والأثر: الوقت والتكلفة |
| 5 | الفحص المحلي، والرفع، والمحرك والقاعدة، وMCP |
| 6 | كيف نصلح، بالترتيب |
| 7 | التغطية والبوابة والـ pipeline |
| 8 | الأدوات والتشغيل والأعطال |
| 10 | جولة في السيرفر، شاشة بشاشة |
| 11 | المصادر |

القسم 9 غير مستخدم. الترقيم يقفز من 8 إلى 10 عمدًا.

## الفكرة التي يدور عليها الدليل

الحزمة على الجهاز تُظهر التحذيرات ولا ترفع. الإضافة تسطّر الملف المفتوح وليست خطوة في الخريطة. الرفع يرسل تقريرًا ولا يحكم. المحرك والقاعدة يحسبان البوابة على الكود الجديد فقط. عندنا بداية الكود الجديد هي Previous version، والإصدار ثابت `1.0`، واللوحة تقول `New Code Since 15044e5`.

Community بلا تحليل فروع: كل رفع يستبدل عرض المشروع. `Reference branch` لا يعمل عندنا.
